# Política de segurança

## Versões com suporte

A versão mantida é a versão mais recente disponível neste repositório.

## Como reportar uma vulnerabilidade

Não publique detalhes de uma vulnerabilidade em uma issue ou discussão pública.
Envie um relato privado ao mantenedor pelo canal de contato privado disponível no
perfil do GitHub. Inclua os passos para reproduzir o problema, o impacto
observado e, se possível, uma sugestão de mitigação. Não inclua dados pessoais,
credenciais ou informações de usuários reais no relato.

Os relatos serão avaliados assim que possível. Não há prazo de resposta ou
garantia de divulgação coordenada definidos neste momento.

## Escopo

Esta política cobre o código e os arquivos mantidos neste repositório. Ela não
confirma a segurança de uma implantação específica, de proxies, provedores de
hospedagem ou infraestrutura operada por terceiros.
